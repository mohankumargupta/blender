Taken from [image texture](https://youtu.be/KMjTLE0z80k?si=nJz97_1xgdm-6wcY)

Procedure

1. Use default cube to add image texture of wooden crate.
2. Select cube, then go to Material Properties
3. For starters, we will try to change color of cube to brown color
   - Click new
   - Go to Base Color, click on color wheel
   - Under Hex, choose #674121
4. To add Image Texture instead:
   - press backspace removes base color
   - click the dot to the left of Base Color entry, choose Image Texture
   - press open and choose texture called crate_texture.png
5. You won't see the texture because we are in Solid Viewport mode.
   Need to change to either Material Preview or Rendered mode.
6. It doesn't look quite right, we are going to do UV unwrapping without explaining what that is to fix that.
   - Go into Edit Mode by pressing tab
   - Press A to select all
   - Press U for unwrap menu then press Cube Projection

Further going to explain lighting briefly

- Shift + A: add light source -> Area
- use G,R,S to move rotate scale, although for light source G (move)
  is the most appropriate
- play with color and power
